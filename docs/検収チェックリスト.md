# Title Studio 検収チェックリスト

作成日：2026年11月18日
対象：要件定義「23．検収条件」と、画面設計書「画面の確認項目」

## 状態の見方

| 記号 | 意味 |
|---|---|
| ✅ | 確認済み（開発中の試験、または利用者の画面確認で確かめた） |
| 👀 | 画面で確認が必要（利用者が実際の画面・端末で確かめる） |
| 🔧 | 検収で作り忘れが見つかり、修正した（画面確認が必要） |

確認方法の略語：**試験**＝プログラムによる自動試験、**API**＝サーバーへの実際のリクエスト、**画面**＝利用者による画面操作、**本番**＝公開先（Vercel）での確認。
